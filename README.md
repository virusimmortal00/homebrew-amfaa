# homebrew-amfaa

Homebrew distribution for [All My Friends Are Agents](https://github.com/virusimmortal00/AllMyFriendsAreAgents) is paused. The previous cask has been removed because its bundled OpenCode executable failed macOS code-signature verification and could be blocked by Gatekeeper.

Install from the native shell installer in the [main README](https://github.com/virusimmortal00/AllMyFriendsAreAgents#quick-start) while Developer ID signing and notarization are prepared. This repository no longer syncs or serves a Homebrew cask.
